Dripland Barbershop Website



The **Dripland Barbershop Website** is a multi-page website developed for Dripland Barbershop, a local barbershop based in Mkhuhlu, Mpumalanga, South Africa. The purpose of the website is to create a professional online presence for the business and make important information about its services easily accessible to customers.

The website provides customers with information about the barbershop, available grooming services, prices, photographs of the business and its work, contact information, and enquiry/booking options.

This project was developed as part of a web development assignment, with the website being built progressively from a basic HTML structure before introducing styling and additional functionality.

---

## 🏪 Background of Dripland Barbershop

Dripland Barbershop was established in **2019** with the aim of providing customers with quality haircuts and professional grooming services. Over time, the barbershop has developed a loyal customer base by focusing on quality haircuts, modern hairstyles, beard grooming and good customer service.

The business operates within the local community of Mkhuhlu, Mpumalanga, and provides grooming services for different types of customers, including adults and children.

The website was created because a professional online presence can help customers find information about the business more easily, view examples of its work, understand the available services and make enquiries or bookings.

---

## 🎯 Website Objectives

The main objectives of the website are to:

* Create a professional online presence for Dripland Barbershop.
* Provide customers with information about the business.
* Display the services offered by the barbershop.
* Display service prices where applicable.
* Showcase photographs of the barbershop and its work.
* Allow customers to make service enquiries.
* Provide contact and booking information.
* Make navigation between different sections of the website simple and clear.
* Create a foundation that can later be improved with CSS styling and JavaScript functionality.

---

## 🌐 Website Pages

The website currently consists of the following main pages:

### 1. Home Page – `index.html`

The home page introduces visitors to Dripland Barbershop. It provides a brief description of the business, highlights some of its main services and encourages customers to make an appointment.

### 2. About Us – `about.html`

The About Us page provides background information about Dripland Barbershop, including its history, mission, vision and reasons why customers may choose the barbershop.

### 3. Services – `services.html`

The Services page provides information about the grooming services offered by Dripland Barbershop. These include different haircut, beard grooming, hairstyling and children's haircut services.

### 4. Gallery – `gallery.html`

The Gallery page showcases photographs of Dripland Barbershop and examples of its work. Real photographs were added to the website's `images` folder and displayed using HTML image elements.

### 5. Contact and Booking – `contact.html`

The Contact and Booking page provides customers with a way to find contact information and access the booking section of the website.

### 6. Enquiry – `enquiry.html`

The Enquiry page allows potential customers to submit an enquiry about the barbershop's services. The form collects information such as the customer's name, email address, phone number, preferred service and enquiry message.

# 🗓️ Development Timeline

The website was developed in stages to ensure that each major requirement was completed before moving to the next stage.

### Phase 1 – Planning and Research

**Milestone 1: Business Selection**

Dripland Barbershop was selected as the business for the website project.

**Milestone 2: Website Planning**

The main purpose of the website, target users, required pages and information to be displayed were identified.

**Milestone 3: Website Structure**

The main pages were planned:

* Home
* About Us
* Services
* Gallery
* Contact and Booking
* Enquiry

---

### Phase 2 – HTML Development

**Milestone 4: Home Page**

The `index.html` page was created to introduce visitors to Dripland Barbershop.

**Milestone 5: About Page**

The `about.html` page was created with the business background, mission, vision and reasons to choose Dripland Barbershop.

**Milestone 6: Services Page**

The `services.html` page was created to display the different grooming services and their prices.

**Milestone 7: Gallery Page**

The `gallery.html` page was created and photographs of the barbershop and its work were added to the website.

**Milestone 8: Contact and Booking Page**

The `contact.html` page was developed to provide customers with contact and booking information.

**Milestone 9: Enquiry Page**

The `enquiry.html` page was added with a customer enquiry form containing text fields, a service selection menu, a message area and form buttons.

---

### Phase 3 – Website Testing

**Milestone 10: Navigation Testing**

Each navigation link was tested to ensure that visitors could move between the website pages.

**Milestone 11: Image Testing**

The images were tested to ensure that they displayed correctly from the website's `images` folder.

**Milestone 12: Form Testing**

The enquiry form was tested to ensure that all required fields and controls were displayed correctly.

**Milestone 13: Browser Testing**

The website was opened using a local development server and checked in a web browser.

---

### Phase 4 – Styling and Enhancement

**Milestone 14: CSS Styling**

CSS styling was introduced to improve the appearance, spacing, typography, navigation and overall layout of the website.

**Milestone 15: Responsive Design**

The website layout was improved so that it can adapt to different screen sizes, including computers, tablets and mobile devices.

**Milestone 16: JavaScript Functionality**

JavaScript functionality can be added to improve user interaction, form behaviour, navigation and other interactive elements.
